# Security and sensitive-material reporting

The public selection is not a complete supported deployment. No security certification or response-time commitment is implied.

Do not post credentials, individual-level research data, private endpoints, exploit payloads containing sensitive data or unpublished material in a public issue or pull request. Seek a private contact route from the project owner's [academic website](https://ichsan.ibios.org) before transmitting details. No verified dedicated security email or private GitHub advisory channel is established by this candidate.

If a secret is discovered, stop publication, notify the owner privately and consider revocation/rotation using the service's secure administration process. Rewriting Git history requires a separate explicit decision; a clean latest tree does not erase earlier disclosure.

The publication review is a bounded file/content review, not an application penetration test or guarantee that every historical secret has been detected.
