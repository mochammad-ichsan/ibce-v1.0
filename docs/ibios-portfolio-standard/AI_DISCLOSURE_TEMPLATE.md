# AI disclosure template

## Evidence-backed statement

[Project] used [confirmed researcher/AI workflow]. [Confirmed people] contributed [specific evidenced activities]. [Confirmed tools] assisted with [implementation, ideation, translation or other verified tasks]. Attribution not established by records remains [requires confirmation].

Do not assert that the named researcher wrote all code or designed every method. Do not infer programming competence, scientific validity or independent review from AI-generated implementation.

## Contribution evidence

Record conceptualization, questions, methodology, data/algorithm selection, implementation, interpretation, testing and dissemination separately. State evidence and reviewer for each.

## Runtime AI

If applicable, distinguish development assistance from models called by the product. Document input/output scope, known failure modes, human oversight and evidence limits without exposing private prompts or research material.

## Confirmation

[Researcher confirms roles, collaborators, acknowledged tools and wording before publication.] Never populate this confirmation on the researcher's behalf.

**RESEARCHER_CONFIRMED** means direct affirmation, **DOCUMENTED** means inspectable artifact, **INDEPENDENTLY_VERIFIED** means a bounded check against separate evidence/reference, and **REQUIRES_REVIEW** means unresolved. Neither confirmation nor implemented code independently verifies historical authorship. Computational independence is not independent human peer review.

Disclose AI suggestions in scientific, methodological and technical work where confirmed, not only code generation. Do not claim all ideas or code were manually produced by one researcher. Review the complete author list separately from this matrix.
