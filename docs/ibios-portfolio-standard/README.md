# IBIOS Research Software Portfolio Standard v1.0

A reusable **documentation standard**, not an application framework or scientific certification. Its reference implementation is the [IBCE portfolio](../../README.md); another project must not inherit IBCE's claims, license, results or methodological assumptions.

## Universal requirements

1. Record a baseline and the approved public/private distribution boundary.
2. Identify the project and scientific purpose without unsupported claims.
3. Link each material claim to source inspection, tests, data or literature.
4. Distinguish objectives, implemented capabilities, observed results and validation.
5. Attribute researcher and AI contributions honestly.
6. State reproducibility, data-rights, security, licensing and publication limits.
7. Run and record scoped checks; mark unrun checks explicitly.
8. Require human approval before public actions.

Methods, cohorts, data units, validation standards and risk controls are project-specific. Documentation quality does not confer biological, clinical, regulatory or educational validity.

The v1.1.1 IBCE remediation expands this v1.0 documentation standard without declaring an application release: researcher-led AI contribution matrices, explicit provenance/outcome states, independent numerical-reference requirements, runtime records, asset provenance and a blocking publication-approval gate. Templates contain no transferable IBCE scientific result or researcher confirmation.
